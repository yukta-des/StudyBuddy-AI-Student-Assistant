# StudyBuddy — AI Student Assistant

An AI-powered learning assistant that helps students solve coding, database, mathematics, and logical reasoning problems through guided hints instead of direct answers. The platform promotes active learning by combining adaptive AI assistance, progress analytics, and a gamified achievement system.

## 🌟 Key Features

### 🧠 Intelligent Problem Analysis

* Accepts both text and image-based questions.
* Automatically analyzes the subject and classifies question difficulty into three levels (Difficulty 1–3).
* Generates personalized guidance based on problem complexity.

### 💡 Progressive Hint System

* Provides up to **5 Socratic-style hints** that gradually guide students toward the solution.
* Encourages independent thinking by revealing increasingly detailed guidance.
* Before revealing the 4th or 5th hint, prompts users with a confirmation dialog to view the complete worked solution.

### 📊 Learning Analytics

* Tracks the number of solved questions.
* Records how many hints were used for every question.
* Displays performance statistics and progress dashboards to help students improve problem-solving skills.

### 🏆 Achievement System

The achievement system unlocks after students solve three questions and rewards consistent improvement through five progression stages:

* 🥉 **Bronze:** Solve 5 Difficulty 3 questions.
* 🥈 **Silver:** Solve 15 Difficulty 3 questions with at least 3 solved using no more than 2 hints.
* 🥇 **Gold:** Solve 25 Difficulty 3 questions with at least 5 solved using only 1 hint.
* 💎 **Platinum:** Solve 30 Difficulty 3 questions with at least 7 solved without hints.
* 👑 **Master:** Solve 50 Difficulty 3 questions with at least 10 solved without hints.
